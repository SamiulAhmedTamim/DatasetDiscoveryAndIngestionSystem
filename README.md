# DeepShield

A Trust-Aware Framework for Automated Discovery, Quality Assessment, and Ranking of Deepfake Datasets.

## Features

- Multi-source dataset discovery
- GitHub crawler
- HuggingFace crawler
- Kaggle crawler
- Zenodo crawler
- PapersWithCode crawler
- arXiv crawler
- Relevance filtering
- Duplicate removal
- Metadata extraction
- Quality Score
- Trust Score
- Automatic dataset ranking
- SQLite storage
- Statistical analysis

## Installation

pip install -r requirements.txt

## Run

python main.py

## Statistics

python experiments/statistics.py
